# 러닝 근력 트레이닝 🏃

러닝을 위한 하체·코어 근력 루틴 타이머. 모바일 브라우저 한 화면에 꽉 차게 동작하며,
음성 안내와 카운트다운 벨로 눈을 화면에서 떼고도 운동할 수 있습니다.

## 루틴 (기본값)

한 세트 = 다음 3가지 동작

| 순서 | 동작 | 시간 |
|---|---|---|
| 1 | 월 싯 (Wall Sit) | 40초 |
| 2 | 힙 브릿지 (Hip Bridge) | 40초 |
| 3 | 사이드 레그 레이즈 (Side Leg Raise) | 한쪽 20초 × 좌우 (다리 교체 5초) |

- 운동 사이 휴식 **10초**
- 세트 사이 휴식 **30초**
- **3세트** 반복 · 시작 전 준비 10초
- 총 약 **8분 25초**

모든 숫자는 **설정**에서 바꿀 수 있고, 값은 브라우저(localStorage)에 자동 저장됩니다.

## 테마

설정 맨 위 **화면 → 테마**에서 선택합니다.

| 값 | 동작 |
|---|---|
| 시스템 (기본) | iOS/Android 다크모드 설정을 그대로 따라감 |
| 라이트 | 기기 설정과 무관하게 항상 밝게 |
| 다크 | 기기 설정과 무관하게 항상 어둡게 |

상태바 색(`theme-color`)도 현재 화면(홈 / 운동 / 휴식)에 맞춰 자동으로 바뀝니다.

## 기능

- 📸 동작마다 배경을 뺀 자세 사진 — 좌/우 구분은 사진을 좌우 반전해서 표시
- 🌙 다크모드 — 기기 설정 자동 따라가기 / 라이트 고정 / 다크 고정 (설정 → 화면 → 테마)
- 📱 모바일 한 화면 고정 — 스크롤 없음, 화면 높이에 맞춰 요소가 비례 배치됨, 주소창/노치 영역(safe-area) 대응
- 🔔 종료 5초 전부터 매초 벨 카운트다운 (초 수 조절 가능), 마지막 1초는 음이 올라감
- 🔕 아이폰 무음 모드에서도 벨이 들리도록 처리 (설정에서 끌 수 있음)
- 🗣 한국어 음성 안내 — 다음 동작, 좌/우, 휴식, 세트 전환
- 📳 진동 피드백
- ⏸ 화면 가운데 탭 → 일시정지 / 계속
- ⏭ 이전·다음 구간 건너뛰기
- 🔅 운동 중 화면 꺼짐 방지 (Wake Lock)
- 🏠 홈 화면에 추가하면 전체화면 앱처럼 실행 (PWA manifest)

## 사용법

브라우저에서 열고 **시작하기**만 누르면 됩니다.

### 아이폰 무음 모드

아이폰은 벨소리/무음 스위치가 무음이면 브라우저의 효과음(카운트다운 벨, 전환 차임)을 막습니다.
음성 안내만 들리고 벨이 안 들린다면 이게 원인입니다.

설정의 **무음 모드에서도 벨**이 기본으로 켜져 있어 무음 상태에서도 소리가 나지만,
그 대신 다른 앱에서 재생 중인 음악이 멈출 수 있습니다. 음악을 들으면서 운동한다면
이 옵션을 끄고 무음 스위치를 해제하세요. (iOS 16.4 이상에서 동작)

> **처음 한 번은 꼭 화면을 탭해서 시작**하세요. iOS/Android 모두 사용자가 직접 터치한
> 뒤에야 소리와 음성 재생이 허용됩니다. 설정의 **소리 테스트** 버튼으로 미리 확인할 수 있습니다.
>
> iPhone에서는 Safari로 열고 `공유 → 홈 화면에 추가`를 하면 주소창 없이 전체화면으로 쓸 수 있습니다.

### 조작

| 동작 | 결과 |

| 가운데 화면 탭 | 일시정지 / 계속 |

## 배포 (GitHub Pages)

정적 파일뿐이라 빌드가 필요 없습니다.

1. GitHub 저장소 → **Settings → Pages**
2. **Source** 를 `Deploy from a branch` 로 두고
3. Branch 를 `main` (또는 이 브랜치) / 폴더는 `/ (root)` 선택 후 Save

잠시 뒤 `https://<계정>.github.io/home-workout/` 에서 열립니다.

> 음성·진동·Wake Lock은 HTTPS에서만 동작합니다. GitHub Pages는 기본 HTTPS라 그대로 사용 가능합니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 파일 구성

```
index.html            화면 구조 (홈 / 운동 / 완료 / 설정 시트)
style.css             전체 스타일, 한 화면 고정 레이아웃
app.js                루틴 생성, 타이머 엔진, 음성·벨, 설정 저장
img/*.webp            동작 사진, 투명 배경 (큰 것 + 목록용 작은 것) 전체 176KB
manifest.webmanifest  홈 화면 추가용 PWA 설정
icon.svg, icon-*.png  아이콘
```

사진을 바꾸려면 `img/` 안의 파일을 같은 이름으로 교체하고, `app.js` 위쪽 `FIG` 객체의
가로·세로 픽셀값만 맞춰 주면 됩니다.

운동 종류나 순서를 바꾸고 싶으면 `app.js` 위쪽의 `EXERCISES` 배열과 `buildPlan()` 함수만 고치면 됩니다.

## 알려진 제약

- 화면을 끄거나 다른 앱으로 전환하면 브라우저가 타이머를 늦추기 때문에 벨이 정확히 울리지 않을 수 있습니다. 운동 중에는 화면을 켜 두세요 (Wake Lock이 자동으로 꺼짐을 막아 줍니다).
- 음성 안내는 기기에 한국어 TTS 음성이 설치돼 있어야 자연스럽게 들립니다. 없으면 벨 소리만으로도 충분히 사용할 수 있습니다.
